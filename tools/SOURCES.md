# Flashcard Sources (Pass 3)

Generated by `tools/build_flashcards_pass3.py`. Raw source downloads are cached in
`tools/.flashcard-cache/`, which is gitignored. Existing vocabulary and formula cards are
preserved unchanged; only the generated decks are rebuilt.

## Academic Vocabulary (NAWL)

- Source: New Academic Word List, 12th edition lemmatized teaching list
- URL: https://www.newgeneralservicelist.com/new-general-service-list
- License: CC BY-SA 4.0
- Attribution: New General Service List Project
- Local cache: `tools/.flashcard-cache/nawl.csv`

## Core Vocabulary (NGSL)

- Source: New General Service List 1.2, SFI ranks beyond 500
- URL: https://www.newgeneralservicelist.com/new-general-service-list
- License: CC BY-SA 4.0
- Attribution: New General Service List Project
- Local cache: `tools/.flashcard-cache/ngsl.csv`

## Definitions and examples

- Source: Open English WordNet 2025 JSON
- URL: https://en-word.net/
- License: CC BY 4.0 (the underlying Princeton WordNet 3.0 database is also CC BY 4.0)
- WordNet examples are used when available **and contain the headword**. A synset example can
  belong to a synonym instead, so in that case the builder uses a short CC0 sentence from the
  Tatoeba English export and sets `example_source = "tatoeba"`; if neither source has a suitable
  sentence, it writes an original metalinguistic sentence and sets `example_source = "original"`.

## Example sentences (Tatoeba)

- Source: Tatoeba English sentence export (CC0 1.0)
- URL: https://downloads.tatoeba.org/exports/per_language/eng/eng_sentences.tsv.bz2
- The builder streams the compressed export, keeps only short sentences containing an exact
  headword, and never downloads it from PythonAnywhere.

## Words from Real Questions (official Words in Context)

- Source: the locally imported College Board released SAT question bank
- Local input: `public/collegeBoardBank.json` (gitignored, deployment-side)
- Generated output: `public/officialContextCards.json` (gitignored, deployment-side)
- Target word selection: first unique target word per Words-in-Context question
- Front: the blank-bearing sentence from the question (minimal context)
- Back: official answer, rationale, and WordNet definition where available
- License/provenance: College Board public question bank. This asset is generated only from the
  owner's full local source; it is not committed to the reference repository. College Board is not
  affiliated with this site.

## Counts

The committed `src/data/flashcards.json` contains the existing 1,804 cards plus the generated
NAWL and NGSL decks. The local-only official deck is loaded at runtime from
`public/officialContextCards.json`; if the asset is absent (for example in the stripped reference
repo), the other decks still load normally.

Run:

```bash
python tools/build_flashcards_pass3.py --wordnet-dir "C:/Users/venky/AppData/Local/Temp/oewn"
```

The script prints the actual per-deck counts and dedupe skips; those printed counts are the source
of truth for the Pass 3 report.
